## Featured Projects

### 01. AI Instructor – RAG-Based Knowledge Assistant

An AI-powered knowledge assistant built with Spring Boot and Spring AI that allows users to interact with documents and retrieve context-aware answers using Retrieval-Augmented Generation (RAG).

Integrated OpenAI models, Qdrant vector database, document ingestion, semantic retrieval, query transformation and conversational memory to build a document-grounded question-answering system.

**Technologies:** Java, Spring Boot, Spring AI, OpenAI, RAG, Qdrant, Docker.

### 02. Thread-Safe Rate Limiter

A Java-based rate-limiting library implementing Fixed Window, Sliding Window and Token Bucket algorithms to control request traffic. Focuses on concurrent access, thread safety and efficient request management.

**Technologies:** Java, Multithreading, Concurrency.

### 03. BookMyShow – Movie Ticket Booking System

An object-oriented movie ticket booking application focused on domain modeling, booking workflows and extensible system design using core object-oriented principles and design patterns.

**Technologies:** Java, OOP, Design Patterns.

### 04. Parking Lot Management System

An extensible parking management system supporting multiple vehicle types, dynamic pricing and parking slot allocation. Designed using Strategy, Factory and Singleton patterns to demonstrate maintainable object-oriented architecture.

**Technologies:** Java, OOP, SOLID, Design Patterns.

### 05. Hotel Management & Security

A Spring Boot hotel management application implementing backend operations with secure authentication and authorization using Spring Security and Spring Data JPA.

**Technologies:** Java, Spring Boot, Spring Security, JPA.

### 06. Library Management Microservices

A distributed library management platform built using Spring Boot and Spring Cloud, demonstrating independent services, API Gateway, Eureka service discovery and inter-service communication through OpenFeign.

Implemented Redis-based idempotency and caching, rate limiting, retries, circuit breakers, bulkhead isolation and asynchronous event processing with Kafka.

**Technologies:** Java, Spring Boot, Spring Cloud, Kafka, Redis, MySQL, Resilience4j.
